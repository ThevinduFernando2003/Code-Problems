# LeetCode

Solutions for the official [LeetCode 75](https://leetcode.com/studyplan/leetcode-75/) study plan, all in C++.

Each file is a paste-ready `Solution` (or design class) for the LeetCode judge. Linked-list and tree problems include the usual node structs so the file can compile on its own.

Naming: `{id}{camelCaseTitle}.cpp`
