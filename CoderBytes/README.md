# Coderbyte

C++ solutions for every challenge in the [AppDev4Tech Coderbyte playlist](https://www.youtube.com/playlist?list=PL88xup0DHWoYPIu3kIM8NWseGr0o9r-OP).

Each file has the problem statement, worked examples, **pseudocode**, then a complete C++ function you can paste into Coderbyte.

These are original implementations, not copies of the JavaScript from the videos.
