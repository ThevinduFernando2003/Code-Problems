# HackerRank Software Engineer Prep Kit

Python solutions for the [Software Engineer Prep Kit](https://www.hackerrank.com/prep-kit/software-engineer) practice challenges. Each file keeps a HackerRank-style function stub so it can be pasted into the editor.

Practice set: [contest challenges](https://www.hackerrank.com/contests/software-engineer-prep-kit/challenges)

Numbered files `01`–`36` are the solutions for the kit list below. Older unnumbered files in this folder are earlier drafts of overlapping problems.

If a challenge’s official stub name differs, copy the function body into the editor stub. A few early challenges reuse odd generated names from the kit (`minTasksToCancelForNoConflict` is phone combinations).
