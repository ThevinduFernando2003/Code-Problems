# Pygame Games

Original Python games built with Pygame, inspired by the classic titles listed on [itsourcecode Pygame projects](https://itsourcecode.com/topics/free-projects/pygame/). Each game is a self-contained `.py` file.

## Setup

```powershell
cd "Projects/games"
python -m pip install -r requirements.txt
```

## Run

```powershell
python pong.py
python snake.py
python ticTacToe.py
```

Quit any game with `Esc` or by closing the window. Restart with `R` when a game is over.
